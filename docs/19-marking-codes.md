# Управление кодами маркировки и сборкой заказов для FBS/rFBS

> Раздел документации Ozon Seller API (2.1), источник: PDF docs.ozon.ru, стр. 290. Базовый URL: `https://api-seller.ozon.ru`.

Все методы требуют заголовки `Client-Id` (идентификатор клиента) и `Api-Key` (API-ключ), если явно не указано иное.

Коды маркировки товара в системе «Честный ЗНАК» передаются с криптохвостом. Проверьте, что в запросе коды

маркировки сериализованы в соответствии с пунктом 7 стандарта RFC 8259.

Символ <GS> должен кодироваться как последовательность \u001d . Двойное экранирование в виде \\u001d не

допускается. Эта логика уже содержится в большинстве JSON-библиотек — проверьте корректность формируемого

запроса.

## Частичная сборка отправления (версия 4)

`POST /v4/posting/fbs/ship/package`

Если в запросе передать часть товаров из отправления, метод разделит первичное отправление на две части. В первичном несобранном отправлении останется часть товаров, которую не передали в запросе. По умолчанию статус созданных отправлений awaiting_packaging — ожидает сборки. Статус изначального отправления изменится только после изменения статуса отправлений, на которые он разделился.

> **Примечание:** Ответ с кодом 200 не гарантирует успешную сборку отправления.

> **Примечание:** Используйте метод /v3/posting/fbs/get, чтобы проверить, что

> **Примечание:** отправление собрано. Если в ответе указан result.substatus =

> **Примечание:** ship_failed, повторите сборку отправления.

**Тело запроса** (`application/json`):
- **posting_number** `string` *обязательный* — Номер отправления.
- **products** `Array of objects` — Список товаров в отправлении.

**Пример запроса:**

```json
{
  "posting_number": "string",
  "products": [
    {
      "exemplarsIds": [
        "string"
      ],
      "product_id": 0,
      "quantity": 0
    }
  ]
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Результат сборки отправления |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **result** `string` — Номера отправлений, сформированные после сборки.

**Пример ответа (`200`):**

```json
{
  "result": "string"
}
```

## Проверить и сохранить данные экземпляров

`POST /v6/fbs/posting/product/exemplar/set`

Асинхронный метод: для проверки наличия экземпляров в обороте в системе «Честный ЗНАК»; для сохранения данных экземпляров. Чтобы получить результаты проверок, используйте метод созданных экземплярах, используйте метод Если у вас несколько одинаковых товаров в отправлении, укажите один product_id и массив exemplars для каждого товара из отправления. Всегда передавайте полный набор данных по экземплярам и продуктам. Например, в вашей системе 10 экземпляров. Вы передали их для проверки и сохранения. Потом добавили в своей системе ещё 60 экземпляров. При повторной передаче экземпляров для проверки и сохранения укажите все экземпляры: и старые, и только что добавленные. ## Получить статус добавления экземпляров

`POST /v5/fbs/posting/product/exemplar/status`

Метод для получения статусов добавления экземпляров, переданных в методе /v6/fbs/posting/product/exemplar/set. Также возвращает данные по этим экземплярам.

**Тело запроса** (`application/json`):
- **posting_number** `string` *обязательный* — Номер отправления.

**Пример запроса:**

```json
{
  "posting_number": "string"
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Статусы проверки экземпляров |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **posting_number** `string` — Номер отправления.

## Валидация кодов маркировки

`POST /v5/fbs/posting/product/exemplar/validate`

Метод для проверки кодов на соответствие требованиям системы «Честный ЗНАК» по количеству и составу символов, а также других маркировок. Если у вас нет номера грузовой таможенной декларации (ГТД), вы можете его не указывать.

**Тело запроса** (`application/json`):
- **posting_number** `string` *обязательный* — Номер отправления.
- **products** `Array of objects` *обязательный* — Список товаров.

**Пример запроса:**

```json
{
  "posting_number": "string",
  "products": [
    {
      "exemplars": [
        {
          "gtd": "string",
          "marks": [
            {
              "mark": "string",
              "mark_type": "stri"
            }
          ],
          "rnpt": "string",
          "weight": 0
        }
      ],
      "product_id": 0
    }
  ]
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Результат валидации |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **products** `Array of objects` — Список товаров.
  - **error** `string` — Код ошибки.
  - **exemplars** `Array of objects` — Информация об экземплярах.
  - **product_id** `integer <int64>` — Идентификатор товара в системе Ozon — SKU.
  - **valid** `boolean` — Результат прохождения проверки. true , если коды всех экземпляров соответствуют требованиям.

**Пример ответа (`200`):**

```json
{
  "products": [
    {
      "error": "string",
      "exemplars": [
        {
          "errors": [
            "string"
          ],
          "gtd": "string",
          "marks": [
            {
              "errors": [
                "string"
              ],
              "mark": "string",
              "mark_type": "stri \"valid\": true"
            }
          ],
          "rnpt": "string",
          "valid": true,
          "weight": 0
        }
      ],
      "product_id": 0,
      "valid": true
    }
  ]
}
```
