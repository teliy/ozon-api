# Ozon Доставка

> Раздел документации Ozon Seller API (2.1), источник: PDF docs.ozon.ru, стр. 608. Базовый URL: `https://api-seller.ozon.ru`.

Все методы требуют заголовки `Client-Id` (идентификатор клиента) и `Api-Key` (API-ключ), если явно не указано иное.

Методы в разделе Ozon Доставка работают только через OAuth-токен в частном или публичном приложении.
