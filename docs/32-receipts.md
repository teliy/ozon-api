# Чеки

> Раздел документации Ozon Seller API (2.1), источник: PDF docs.ozon.ru, стр. 413. Базовый URL: `https://api-seller.ozon.ru`.

Все методы требуют заголовки `Client-Id` (идентификатор клиента) и `Api-Key` (API-ключ), если явно не указано иное.

Подробнее о чеках в Справке для продавцов Ozon Global.

## Получить чек в формате PDF

`POST /v1/receipts/get`

> **Примечание:** Метод доступен продавцам, которые заключили договор с ТОО

> **Примечание:** «ОЗОН Маркетплейс Казахстан».

**Тело запроса** (`application/json`):
- **receipt_id** `string` *обязательный* — Идентификатор чека. Получите значение параметра методом /v1/receipts/seller/list.

**Пример запроса:**

```json
{
  "receipt_id": "string"
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Чек |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **content** `string <byte>` — PDF-файл с чеком в бинарном виде.

**Пример ответа (`200`):**

```json
{
  "content": "string"
}
```

## Получить список чеков продавца

`POST /v1/receipts/seller/list`

> **Примечание:** Метод доступен продавцам, которые заключили договор с ТОО

> **Примечание:** «ОЗОН Маркетплейс Казахстан».

**Тело запроса** (`application/json`):
- **page** `integer <int64>` — Количество страниц, которое нужно пропустить.
- **page_size** `integer <int64>` — Количество элементов на странице.
- **posting_numbers** `Array of strings` — Фильтр по номерам отправлений.

**Пример запроса:**

```json
{
  "page": 0,
  "page_size": 100,
  "posting_numbers": [
    "string"
  ]
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Список чеков продавца |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **has_next** `boolean` — Признак, что в ответе вернулись не все записи: true — сделайте повторный запрос с новым параметром page , чтобы получить остальные значения; false — ответ содержит все записи с чеками.
- **receipts** `Array of objects` — Информация о чеках.

**Пример ответа (`200`):**

```json
{
  "has_next": true,
  "receipts": [
    {
      "created_at": "2019-08-24T14:15: \"operation_type\": \"UNSPECIFIED",
      "order_id": 0,
      "parent_receipt_id": "string",
      "posting_numbers": [
        "string"
      ],
      "receipt_id": "string",
      "receipt_number": "string",
      "type": "UNSPECIFIED",
      "updated_at": "2019-08-24T14:15: }"
    }
  ]
}
```

## Загрузить чек

`POST /v1/receipts/upload`

> **Примечание:** Метод доступен продавцам, которые заключили договор с ТОО

> **Примечание:** «ОЗОН Маркетплейс Казахстан».

**Тело запроса** (`application/json`):
- **content** `string <byte>` *обязательный* — Содержание файла в бинарном виде.
- **operation_type** `string` *обязательный* — Тип операции. Получите значение параметра методом /v1/receipts/seller/list.
- **parent_receipt_id** `string` — Идентификатор родительского чека. Передайте параметр с идентификатором чека, который нужно изменить.
- **posting_numbers** `Array of strings` *обязательный* — Номера отправлений.
- **receipt_number** `string` *обязательный* — Номер чека.
- **type** `string` *обязательный* — Тип чека: INCOMING — чек реализации; REFUND — чек возврата.. Enum: `"INCOMING"`, `"REFUND"`.

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Чек загружен |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **receipt_id** `string` — Идентификатор чека.

**Пример ответа (`200`):**

```json
{
  "receipt_id": "string"
}
```
