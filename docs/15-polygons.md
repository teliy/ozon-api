# Полигоны

> Раздел документации Ozon Seller API (2.1), источник: PDF docs.ozon.ru, стр. 225. Базовый URL: `https://api-seller.ozon.ru`.

Все методы требуют заголовки `Client-Id` (идентификатор клиента) и `Api-Key` (API-ключ), если явно не указано иное.


## Создайте полигон доставки

`POST /v1/polygon/create`

Вы можете добавить полигон к методу доставки. Создайте полигон, получив его координаты на https://geojson.io: отметьте на карте минимум 3 точки и соедините их линиями.

> **Примечание:** Сервис geojson.io возвращает координаты в формате [[[long

> **Примечание:** lat]]] . Поменяйте местами широту и долготу в запросе метода.

**Тело запроса** (`application/json`):
- **coordinates** `string` *обязательный* — Координаты полигона доставки в формате [[[lat long]]] .

**Пример запроса:**

```json
{
  "coordinates": "[[[30.149574279785153,59"
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Полигон создан |
| `400` | Неверный параметр |
| `403` | Доступ запрещён |
| `404` | Ответ не найден |
| `409` | Конфликт запроса |
| `500` | Внутренняя ошибка сервера |

**Схема ответа (`200`):**
- **polygon_id** `integer <int64>` — Идентификатор полигона.

**Пример ответа (`200`):**

```json
{
  "polygonId": "1323"
}
```

## Связать метод доставки с полигоном

`POST /v2/polygon/bind`

**Тело запроса** (`application/json`):
- **delivery_method_id** `integer <int64>` *обязательный* — Идентификатор метода доставки.
- **polygon_id** `integer <int64>` *обязательный* — Идентификатор полигона.
- **time** `integer <int64>` *обязательный* — Время доставки в минутах.
- **warehouse_id** `integer <int64>` *обязательный* — Идентификатор склада.

**Пример запроса:**

```json
{
  "delivery_method_id": 0,
  "polygon_id": 0,
  "time": 15,
  "warehouse_id": 0
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `default` | Ошибка |

**Пример ответа (`default`):**

```json
{
  "code": 0,
  "details": [
    {
      "typeUrl": "string",
      "value": "string"
    }
  ],
  "message": "string"
}
```

## Свяжите метод доставки с полигоном доставки

`POST /v1/polygon/bind`

> **ВНИМАНИЕ:** метод устарел или устаревает и будет отключён. Используйте актуальную версию.

> **Примечание:** Метод устаревает и будет отключён в будущем. Переключитесь

> **Примечание:** на /v2/polygon/bind .

**Тело запроса** (`application/json`):
- **delivery_method_id** `integer <int32>` *обязательный* — Идентификатор метода доставки.
- **polygons** `Array of objects` *обязательный* — Список полигонов.
- **warehouse_location** `object` *обязательный* — Расположение склада.

**Пример запроса:**

```json
{
  "delivery_method_id": 0,
  "polygons": [
    {
      "polygon_id": "1323",
      "time": "30"
    }
  ],
  "warehouse_location": {
    "lat": "58.52391272075821",
    "lon": "31.236791610717773"
  }
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Успешно |
| `400` | Неверный параметр |
| `403` | Доступ запрещён |
| `404` | Ответ не найден |
| `409` | Конфликт запроса |
| `500` | Внутренняя ошибка сервера |

**Пример ответа (`200`):**

```json
{}
```

## Получить список установленных полигонов на метод доставки

`POST /v1/polygon/list`

**Тело запроса** (`application/json`):
- **delivery_method_id** `integer <int64>` *обязательный* — Идентификатор метода доставки.
- **warehouse_id** `integer <int64>` *обязательный* — Идентификатор склада.

**Пример запроса:**

```json
{
  "delivery_method_id": 0,
  "warehouse_id": 0
}
```

**Ответы:**

| Код | Описание |
|---|---|
| `200` | Список полигонов |
| `default` | Ошибка |

**Схема ответа (`200`):**
- **polygons** `Array of objects` — Список полигонов.
  - **coordinates** `string` — Координаты полигона доставки в формате [[[lat,long],[lat,long]]] .
  - **polygon_id** `integer <int64>` — Идентификатор полигона.
  - **time** `integer <int64>` — Время доставки в минутах.

**Пример ответа (`200`):**

```json
{
  "polygons": [
    {
      "coordinates": "string",
      "polygon_id": 0,
      "time": 0
    }
  ]
}
```
