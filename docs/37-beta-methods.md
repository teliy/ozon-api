# Бета-методы

> Раздел документации Ozon Seller API (2.1), источник: PDF docs.ozon.ru, стр. 441. Базовый URL: `https://api-seller.ozon.ru`.

Все методы требуют заголовки `Client-Id` (идентификатор клиента) и `Api-Key` (API-ключ), если явно не указано иное.

Бета-методы Seller API — раздел с методами, которые находятся на стадии тестирования. Такие методы могут работать

нестабильно, а их запросы и ответы могут меняться. Об изменениях в работе бета-методов уведомляем за неделю в

сообществе разработчиков Ozon for dev. В сообществе вы также можете оставить обратную связь по работе бета-

методов и предложить свои идеи.

Бета-методы доступны по API-ключам в зависимости от вашей роли.
